# Django Chat Application using WebSockets

This project is a simple real-time chat application built using Django and WebSockets. The application allows multiple users to join chat rooms and send messages to each other in real-time.

## Features

- Real-time messaging with WebSockets
- Multiple chat rooms
- User authentication (login/logout)
- Message persistence (stored in the database)

## Requirements

- Python 3.8 or higher
- Django 3.0 or higher
- Channels (for WebSockets support)
- Redis (for handling WebSocket connections)
- Django Channels Redis (for real-time chat functionality)
